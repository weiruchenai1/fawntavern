个人信息收集清单

更新日期：2026年8月18日
生效日期：2026年8月18日

本清单列明 FawnTavern 在不同功能场景中处理的信息。未列明的信息不会被应用主动收集；你主动配置的第三方服务可能按照其自身规则处理额外信息。

收集场景使用目的收集方式个人信息类型
聊天和本地工作空间创建会话、保存和展示聊天记录，构建提示内容用户主动输入、导入或保存聊天文本、会话标题、角色卡、世界书、预设、用户昵称、头像及相关本地配置
发送 AI 请求向你选择的 AI 服务提交请求并接收回复用户点击发送后处理输入文本、对话上下文、角色和预设内容、模型名称、请求参数，以及你主动附加的图片和文件
搜索和语音合成完成你主动发起的搜索或 TTS 请求用户主动输入或点击功能后处理搜索关键词、待合成文本、语言和音频设置、请求参数及网络请求元数据
图片、附件和文件发送消息附件、显示角色或远程图片、执行导入导出用户主动选择、拍摄、导入或导出图片、文件内容、文件名、文件类型、文件大小和本地文件路径
API 和服务配置连接你选择的 AI、搜索、TTS 或图片服务用户主动填写或修改服务地址、模型名称、请求参数、访问密钥和相关开关
备份、恢复和数据管理导出、导入、恢复或删除本地工作空间用户主动操作备份文件中的角色卡、预设、世界书、聊天记录、附件、配置和头像
插件运行加载已安装插件并执行插件功能用户安装、启用插件后处理插件清单、脚本、插件配置和传给插件的输入；插件自行发起网络请求时还可能处理其请求数据
应用适配和本地故障诊断适配界面、定位本地错误和保障应用运行应用运行时读取或生成Android 版本、设备型号、应用版本、运行状态、本地崩溃堆栈和安全日志
远程诊断和使用统计统计启动事件、分析崩溃并改进稳定性取得隐私同意且远程诊断开关启用后由 SDK 处理应用实例标识、设备和系统信息、应用版本、构建类型、崩溃堆栈、运行状态及诊断日志；Bugly 可能处理设备标识和隐私相关诊断信息
网络通信和地区判断完成网络请求、选择远程诊断服务区域、检查更新网络请求自动产生IP 地址、请求时间、目标地址、请求头、网络类型、响应状态和其他网络元数据

本地信息默认保存在设备上。发送给你选择的 AI、搜索、TTS、图片或更新服务的信息，由相应服务商按照其规则处理。
