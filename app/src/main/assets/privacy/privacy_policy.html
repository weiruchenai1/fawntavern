隐私政策

更新日期：2026年8月18日
生效日期：2026年8月18日

本隐私政策适用于 FawnTavern 应用及其本地工作空间功能。FawnTavern 是一个以本地存储为基础的聊天工具，应用不会要求你注册账号。我们会按照合法、正当、必要和透明的原则处理信息，并在需要取得同意时先征得你的明确同意。

一、我们收集和处理的信息

1. 本地工作空间内容。包括你主动创建、输入、导入或保存的聊天消息、会话标题、角色卡、世界书、预设、图片、附件、语音合成设置、搜索设置和应用偏好。这些内容默认只保存在你的设备上。

2. 服务配置和密钥。包括你主动填写的 API 地址、模型名称、请求参数和访问密钥。它们用于连接你选择的 AI、搜索或语音服务，并按应用功能保存在设备本地。

3. 你主动发起的网络请求。当你发送消息、搜索、生成语音、加载远程图片或使用其他网络功能时，应用会把完成该请求所需的输入发送到你选择的服务地址。请求可能包含 URL、请求头、网络元数据以及你主动提交的内容；接收方的处理和保存期限由相应服务商决定。

4. 设备和应用信息。应用可能处理 Android 版本、设备型号、应用版本和运行状态，用于界面适配、故障排查和安全运行。除非你同意启用相关功能，这些信息不会被主动上传。

5. 崩溃报告、安全日志和使用统计。崩溃报告和安全日志默认在本地生成和保存。远程诊断和使用统计只有在你同意隐私政策且对应开关处于开启状态时才会运行；你可以在设置中关闭该功能。

远程诊断上传说明。根据设备所在地区和发布配置，应用会使用 Firebase Analytics、Firebase Crashlytics 或 Bugly 提供远程诊断。可能上传的信息包括应用实例标识、设备标识、设备型号和制造商、操作系统与网络信息、IP 地址、应用包名和版本、构建类型、崩溃堆栈、线程和运行状态、诊断日志及应用启动事件。为选择远程诊断服务区域，应用还可能通过 Cloudflare 获取与 IP 地址对应的国家或地区代码。应用不会主动把聊天正文、附件内容或 API 密钥作为远程诊断字段上传。

6. 插件数据。如果你安装或启用插件，应用会在本地读取插件脚本、清单和插件运行所需的输入。插件是否访问网络、访问哪些数据取决于插件本身及你的配置。

二、处理信息的目的

我们处理上述信息是为了保存和展示你的工作空间，完成你发起的 AI、搜索、语音合成、图片和插件请求，提供备份与导入导出功能，改善兼容性和稳定性，以及在你主动提交问题时协助排查故障。

除完成你主动发起的请求、履行法律义务或保护应用安全所必需的情形外，应用不会出售聊天内容，不会将聊天内容用于广告画像，也不会把聊天内容主动提供给无关的第三方。

三、第三方服务和信息共享

应用本身不运营 AI、搜索或语音服务。你配置并使用第三方服务时，相关输入会发送给对应服务商。第三方服务商可能根据其自身规则处理 IP 地址、账号标识、请求内容和网络日志。

应用使用的组件、提供方、处理字段和使用目的，已在应用内的“第三方信息共享清单”中列明。除你主动发起的网络请求外，应用不会主动向这些服务共享聊天内容。

四、信息存储期限和地点

本地工作空间、配置、密钥和日志通常保存在你的设备中，直到你主动删除、清除应用数据或卸载应用。导出的备份文件由你自行管理。发送给第三方服务的信息，其存储地点和期限由相应服务商决定；请在配置服务前查阅其规则。

应用不会为了隐私政策本身建立远程账号或集中式聊天数据库。可选的远程诊断和统计数据仅在对应功能开启期间按功能需要处理。

五、你的权利和选择

你可以访问、修改、导出或删除设备上的工作空间和配置，可以关闭远程诊断、使用统计及其他可选功能，也可以撤回对隐私政策的同意。你可以在“设置 > 数据管理”中执行数据查看、导出、删除和清理操作。

撤回同意后，应用会停止需要同意的统计和诊断功能，但不影响你管理已经保存在设备上的本地数据。你也可以随时卸载应用或清除应用数据，以删除设备上的相关内容。

六、信息安全

应用通过本地文件隔离、访问控制、受保护的临时文件和安全的导入恢复流程降低数据泄露、误删和损坏风险。你应妥善保管设备、API 密钥和导出备份，不要在公共设备上留下未加密的密钥或备份文件。

七、未成年人保护

如果你未满法定成年年龄，请在监护人指导下阅读并使用本应用。监护人应帮助未成年人合理管理聊天内容、网络请求和插件权限。

八、政策更新

当应用功能、数据处理方式或法律要求发生重大变化时，我们会更新本政策并在应用内重新提示你确认。更新后的版本会标明新的更新日期和生效日期。

九、联系我们

本应用目前不提供应用内隐私请求入口。如果你对本政策、数据处理或隐私权利有疑问，请通过你获取本应用的发布渠道所提供的联系方式联系维护者。
